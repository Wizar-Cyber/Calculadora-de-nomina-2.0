# 📊 Calculadora de Nómina - Workspace

Este repositorio contiene la aplicación web de nómina en `frontend/`.

## 📁 Estructura del workspace

- `frontend/` → aplicación Next.js 15 (código productivo)
- `.vscode/` → configuración de editor
- `.streamlit/` → configuración local de herramientas
- `venv/` → entorno local Python (no forma parte del runtime web)

## 🚀 Cómo ejecutar

Toda la documentación técnica y de ejecución está en:

- `frontend/README.md`

## ☁️ Deploy

El despliegue oficial se realiza en **Vercel** usando `frontend/` como root del proyecto.
